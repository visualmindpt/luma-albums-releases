# Luma Albums — instaladores

Versões publicadas do [Luma Albums](https://lumaalbums.com), editor de álbuns fotográficos para macOS (Apple Silicon e Intel, macOS 14 ou mais recente).

Cada versão está em [Releases](../../releases): descarrega o ficheiro `.dmg`, abre-o e arrasta o Luma Albums para Aplicações. Sem licença, a app funciona como versão de avaliação. Depois de instalada, a app atualiza-se sozinha.

Este repositório tem apenas os instaladores e a lista de versões usada pelas atualizações automáticas; não contém código.
